# D&D Web Multiplayer — คู่มือรันและ deploy

## โครงสร้างไฟล์
```
dnd_web/
├── app.py
├── requirements.txt
├── Procfile
└── templates/
    └── index.html
```
(Flask หา HTML จากโฟลเดอร์ `templates/` เป็นค่า default — ต้องวาง index.html ไว้ในนั้น)

## รันทดสอบในเครื่องตัวเอง
```
pip install -r requirements.txt
python app.py
```
เปิด http://localhost:5000

## เล่นข้ามบ้านได้จริงไหม
ได้ — โค้ดนี้ใช้ Socket.IO ผ่าน HTTP ธรรมดา ไม่ผูกกับ LAN แต่ต้องเอาเซิร์ฟเวอร์ไปวางไว้ในที่ที่มี "ที่อยู่สาธารณะ" บนอินเทอร์เน็ต ไม่ใช่ localhost/127.0.0.1 ในเครื่องคุณเอง เพราะเพื่อนอีกบ้านนึงเข้าเครื่อง localhost ของคุณไม่ได้

ตัวเลือกหลัก ๆ:
1. **Hosting ฟรี/ราคาถูกที่รองรับ WebSocket** เช่น Render, Railway, Fly.io — deploy ครั้งเดียว ได้ URL สาธารณะถาวร ใช้ `requirements.txt` และ `Procfile` ที่เตรียมไว้ได้เลย
2. **เปิดเครื่องตัวเองเป็นเซิร์ฟเวอร์ + ngrok/Cloudflare Tunnel** — เหมาะกับเล่นชั่วคราว ไม่ต้อง deploy ถาวร แต่ลิงก์จะเปลี่ยนทุกครั้งที่เปิดใหม่ (เวอร์ชันฟรี)
3. **เช่า VPS เอง** (DigitalOcean, Vultr ฯลฯ) — คุมได้เต็มที่สุด แต่ต้องตั้งค่าเองมากกว่า

## สิ่งที่แก้ไขจากโค้ดเดิม
- เพิ่ม handler `disconnect` — เดิมถ้าผู้เล่นปิดแท็บ/เน็ตหลุดโดยไม่กดปุ่ม "ย้อนกลับ" ชื่อจะค้างอยู่ในห้องตลอดไป
- ย้าย `SECRET_KEY` ไปอ่านจาก environment variable แทนการ hardcode ในไฟล์ (ปลอดภัยขึ้นเวลาเอาโค้ดขึ้น GitHub)
- ปิด `debug=True` และเอา `allow_unsafe_werkzeug=True` ออกตอนรันจริง (ใช้ `FLASK_DEBUG=1` ตอนพัฒนาถ้าต้องการ)
- เพิ่ม `host='0.0.0.0'` และอ่านค่า `PORT` จาก environment — จำเป็นเวลา deploy บน hosting ส่วนใหญ่
- เพิ่ม `eventlet` และ `gunicorn` ใน requirements พร้อม `Procfile` สำหรับรันแบบ production จริง (dev server ของ Flask เดี่ยว ๆ รับผู้เล่นพร้อมกันเยอะ ๆ ไม่ไหว)

## เปิดใช้ผู้ช่วย AI คิดเนื้อเรื่อง (ให้ DM)
1. สมัคร/ล็อกอิน https://console.anthropic.com แล้วสร้าง API key (ต้องเติมเครดิตเล็กน้อยเพื่อใช้งาน)
2. เอาไปตั้งเป็น Environment Variable บน hosting ที่ deploy อยู่ ชื่อตัวแปร `ANTHROPIC_API_KEY`
   - บน Render: เข้า service ที่ deploy ไว้ > แท็บ Environment > Add Environment Variable
3. ไม่ต้องแก้โค้ดอะไรเพิ่ม พอมี key แล้ว DM จะเห็นแท็บ "🤖 AI" ในเกม ใช้งานได้ทันที
4. ถ้าไม่ได้ตั้งค่า key ไว้ ปุ่มจะขึ้นข้อความแจ้งเตือนแทนการพัง — ไม่ตั้งไว้ก็เล่นส่วนอื่นได้ปกติ
5. AI ตอบกลับมาหา DM คนเดียวก่อนเสมอ (ไม่เข้าแชทอัตโนมัติ) DM อ่านแล้วชอบค่อยกด "ส่งข้อความนี้เข้าแชท" เอง

ค่าใช้จ่ายคิดตามการใช้งานจริงของ Anthropic API (ตามจำนวนคำที่ส่งเข้า-ออก) ไม่ใช่ค่าคงที่รายเดือน ใช้เยอะจ่ายเยอะ ใช้น้อยจ่ายน้อย

## ข้อจำกัดที่ควรรู้ (ยังไม่ได้แก้ เผื่ออยากต่อยอด)
- ข้อมูลห้องเก็บใน RAM (`rooms = {}`) — ถ้าเซิร์ฟเวอร์ restart ห้องทั้งหมดหายหมด เหมาะกับเล่นสด ๆ จบในตัว ไม่เหมาะเก็บ progress ระยะยาว
- ถ้า DM รีเฟรชหน้าเว็บ จะได้ sid ใหม่และไม่ใช่ DM ของห้องเดิมอีกต่อไป (ห้องไม่ถูกปิดจนกว่าจะ disconnect จริง ๆ)
- ยังไม่มีระบบล้างห้องที่ถูกทิ้งร้าง (ไม่มีคนอยู่นาน ๆ) ถ้าเปิดให้คนทั่วไปเข้าถึงเยอะ ๆ ควรเพิ่ม timeout
